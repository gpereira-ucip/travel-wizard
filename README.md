# Travel Wizard

App de viajes de un solo archivo (`index.html`): itinerario, reservas, alertas, valijas y presupuesto. Autor: Gonzalo Gabriel Pereira.

- `index.html`: toda la app.
- `PROYECTO.md`: reglas de trabajo, estado, pedidos y registro. Leer antes de tocar nada.
- `MEJORAS.md`: plan de 200 mejoras, en orden.
- `tests.py`: pruebas (`python3 tests.py live index.html` y `python3 tests.py offline index.html`).

Una tarea programada diaria implementa las mejoras y sube cada versión a la rama `main`.
